# Mission: 深入理解 DSH 的集成原理与实现细节

## 目标学习者

对 AI 原生应用开发感兴趣的技术人员，希望深入理解 DeepSeek Harness (DSH) 的集成机制，而不仅仅是简单调用 API。

## 学习目标

通过系统性的学习和实践，深入理解以下内容：

1. **DSH 的核心架构**：理解 Harness 的本质、两种运行模式（headless / web）及其适用场景
2. **集成模式**：掌握如何将 DSH 作为子进程集成到桌面应用中（Tauri/Electron/其他）
3. **AI 网关设计**：理解统一调度、并发控制、Token 计量、审计追踪的实现原理
4. **安全机制**：理解 read-only 沙箱、approval 策略、内核级安全隔离的实现
5. **数据互通**：掌握 DSH_HOME 共享、工作区注册、preset/skill 同步的机制
6. **品牌与主题定制**：理解如何通过注入脚本实现 iframe 内的品牌定制和主题同步

## 学习成果

完成课程后，学习者能够：

- 清晰阐述 DSH 的架构原理和两种运行模式的区别
- 理解并复用 DSH 集成的关键技术模式（子进程管理、安全沙箱、AI 网关）
- 在自己的项目中安全、高效地集成 DSH
- 理解 Token 计量、成本控制、审计追踪的实现方式
- 掌握 DSH 生态（preset、skill、workspace）的互通机制

## 学习风格

偏好"源码级理解"——通过阅读实际代码、理解设计决策、分析数据流来掌握原理，而非单纯记忆概念。
