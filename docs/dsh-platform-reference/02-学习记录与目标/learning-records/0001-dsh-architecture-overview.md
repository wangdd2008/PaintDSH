## 学习内容

- DSH（DeepSeek Harness）的本质：Node.js CLI 工具
- 两种运行模式的区别：Headless vs Web UI
- 架构图：双引擎 + 双模式

## 关键洞察

1. **Headless 模式**适合"做事"——后台任务、分析型任务、无人值守
2. **Web UI 模式**适合"交互"——用户对话、完整 AI 助手体验
3. 两种模式可以共存，通过 AI 网关统一调度
