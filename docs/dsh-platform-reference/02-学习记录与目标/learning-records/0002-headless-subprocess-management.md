## 关键洞察

1. **全局锁的必要性**：Headless 模式的子进程是同步阻塞的，async Mutex 无法跨运行时生效，必须使用 static Mutex
2. **安全沙箱的三层防护**：内核级 read-only + approval=never + defaultPreset
3. **看门狗设计**：100ms 轮询 + 180s 超时 SIGKILL，防止资源泄漏
4. **实时推送机制**：通过闭包逐行回调，支持中途取消
