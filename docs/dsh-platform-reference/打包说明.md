## 各目录说明

### 01-核心调研与设计文档

**`research-dsh-platform.md`**（重点）
- DSH Platform 源码级调研报告
- 覆盖：项目定位、DSH 双引擎/双模式架构、AI 网关、Token 计量、安全沙箱、数据互通、技能管理等
- 第六节「对你构建 AI 原生应用的参考价值」可直接复用

**`DESIGN.md`**
- 产品级完整设计文档
- 包含：13 个功能模块的详细规格、低功耗设计、技术决策记录、目录结构

**`README.md`**
- 项目当前状态速览（已完成 ✅ / 进行中 ⏳）
- 开发命令、目录结构说明

### 02-学习记录与目标

来自 `teach-workspace/` 的教学材料，按 DSH 集成的三个核心主题做了学习记录：

1. **0001** — DSH 架构总览与两种运行模式（Headless vs Web UI）
2. **0002** — Headless 子进程生命周期管理（全局锁、安全沙箱、超时看门狗）
3. **0003** — AI 网关设计（并发控制、Token 计量、SSE 解析）

> 如果新项目中需要复用 DSH 集成模式，这些记录是快速理解实现细节的最佳路径。

### 03-设计原型与截图

- **`design/`**：用 React 写的 UI 原型组件，包含 AI 助手、代码编辑器、命令面板、仪表板、系统监控、终端等模块的设计稿。可作为新项目 UI 设计的视觉参考。
- **`01-dashboard.png`**：工作台 Dashboard 的截图。

## 使用建议

1. **方案设计前**：先通读 `research-dsh-platform.md` + `DESIGN.md`，建立对 DSH Platform 全貌的理解。
2. **需要复用具体模式时**：参考调研报告第五、六节（子进程管理、安全沙箱、品牌定制、数据互通等）。
3. **需要做 UI 方案时**：打开 `design/` 下的原型文件，可作为布局、交互的参考基准。
4. **需要向团队同步时**：`README.md` 是最短路径的概览，`research-dsh-platform.md` 是深度材料。
